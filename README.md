# Minecraft Crossover

**gta5** × Minecraft · visual · idea by the team

GTA V and Minecraft run live together: Minecraft blocks and creatures appear inside Los Santos and react to the player. The change shows in the first 30 seconds of play.

> I packed the Pacific Standard vault with Minecraft diamond ore and let Steve mine it with a pickaxe, and Los Santos paid out in cash.

## Install

Run GTA V story mode (offline) with ScriptHookV and ReShade, and Minecraft Java with Fabric, then drop in the mod's two parts: the plugin for GTA and the jar for Minecraft. Start Minecraft first, then GTA, and the vault scene plays by itself.
